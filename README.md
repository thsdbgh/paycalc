# 급여계산소

연봉 실수령액(국세청 근로소득 간이세액표), 주휴수당, 알바 월급, 최저임금, 퇴직금, 실업급여, 연차, 4대보험, 3.3%·일용직 세금, 연장·야간·휴일수당, 사장님 인건비, 임금명세서 만들기를 제공하는 정적 사이트입니다.

- 사이트: https://thsdbgh.github.io/paycalc
- 계산은 모두 브라우저에서만 이루어지며 입력값은 전송·저장되지 않습니다.

## 빌드
```
python3 build.py --site-url https://thsdbgh.github.io/paycalc   # → dist/
node test/calc.test.js                                          # 계산 테스트
```
`docs/`는 GitHub Pages 배포용 빌드 결과입니다.

## 기준 데이터
- 근로소득 간이세액표: 소득세법 시행령 [별표2] (2024.2.29 개정 표, 2026.2.27 자녀공제 개정 반영)
- 최저임금: 2026년 10,320원, 2027년 10,700원 (고용노동부 고시)
- 4대보험: 2026년 요율, 2027년 국민연금 10%·건강보험 7.19% 동결 반영

계산 결과는 참고용이며 법률·세무 자문을 대신하지 않습니다.
